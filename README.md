# Swible Skills — skill bozori

Swible foydalanuvchilari o‘z montaj skill’larini shu yerda hammaga ulashadi. Har bir skill muallifining username’i ostida turadi:
`skills/<username>/<skill>/<versiya>.zip`. Ro‘yxat — `catalog.json`.

- Skill Hustler’dan **Skill’lar → Mening skill’larim → Ommaga chiqarish** orqali yuboriladi, admin tasdiqlagach shu yerda paydo bo‘ladi.
- Ichida faqat matn va rasm fayllari bo‘ladi (SKILL.md, .md, .json, .png …) — dastur yoki link emas.
- Muallif ixtiyoriy donat havolasini qo‘shishi mumkin (taps.uz, tirikchilik.uz, Payme, Click, Tribute, Buy Me a Coffee, Ko-fi, Patreon, Boosty, PayPal.me). To‘lov muallif bilan siz o‘rtangizda; Hustler pul olmaydi.
